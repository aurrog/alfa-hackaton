# Скоринговая карта

`build_scorecard.py` воспроизводимо (фиксированный seed) строит и валидирует скоринговую карту:

1. генерирует синтетическую выборку МСБ-заёмщиков с известным механизмом дефолта (train / test / out-of-time с дрейфом);
2. бинит 10 признаков и считает WOE/IV, обучает логистическую регрессию на WOE;
3. переводит коэффициенты в баллы (база 600 при шансах 30:1, PDO 40), задаёт грейды A–E по PD;
4. проверяет модель: Gini, KS, PSI по баллам и признакам, калибровка по грейдам (биномиальный тест);
5. сохраняет артефакт `backend/app/domain/scoring/scorecard.json` и отчёт `docs/03-decision/scorecard-validation.md` с графиками.

```bash
pip install -r ml/requirements.txt
python ml/build_scorecard.py
```

Сервис только применяет JSON-артефакт (`app/domain/scoring/scorecard.py`): модель версионируется вместе с кодом,
а каждое решение хранит её версию. Данные синтетические — карта демонстрирует методологию, а не реальный риск.
