# Тестовые данные

Все данные вымышлены и сгенерированы: компании, ИНН, люди, счета, документы, выписки. Совпадения случайны.
Перегенерировать файлы: `pip install reportlab && python scripts/make_test_data.py`.

## Учётные записи

Создаются при первом запуске (`python -m app.seed`), пароль у всех — `Demo-2026`. Полный список и сценарии — в
[README](../README.md#тестовые-учётные-записи) и на странице входа.

В выписках есть операции, которые разборщик обязан исключить из выручки: перевод между своими счетами и поступление
кредита; платежи по кредитам учитываются в долговой нагрузке.
